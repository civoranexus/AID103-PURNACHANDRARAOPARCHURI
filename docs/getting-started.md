## 🚀 QUICK START

### Clone Repository
git clone <assigned-repo-url>  
cd <project-folder>

### Install Dependencies
npm install  
pip install -r requirements.txt

### Start Server
npm run dev  
python app.py  
python manage.py runserver

## 🔄 GIT WORKFLOW (MANDATORY)

Daily routine:
1. Pull latest code
2. Create feature branch
3. Code & test
4. Commit properly
5. Push changes

### Git Commands
git status  
git add .  
git commit -m "feat: implemented feature"  
git push origin feature/your-feature  

### Commit Convention
feat: new feature  
fix: bug fix  
docs: documentation  
refactor: code improvement  
test: tests
