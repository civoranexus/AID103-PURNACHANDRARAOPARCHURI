### 2.1 HTML5

Purpose:
- Core structure of web applications
- Semantic layout
- Accessibility support

Key Concepts:
- Semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
- Forms & validation
- Media handling
- Accessibility attributes (ARIA)

Best Practices:
- Always use semantic HTML
- Avoid div-only layouts
- Use proper labels for forms
- Maintain clean indentation

Example:
```html
<main>
  <section aria-label="Crop Analysis">
    <h1>CropGuard AI</h1>
    <p>Upload crop image for analysis</p>
  </section>
</main>
