CropGuard AI is a **full-stack, AI-driven farm management platform** designed to assist farmers with disease detection, irrigation optimization, analytics, market insights, and decision support.

This project demonstrates:
- End-to-end system design
- Real-world software engineering practices
- AI/ML integration using TensorFlow
- Accessibility (WCAG 2.1 AA) compliance
